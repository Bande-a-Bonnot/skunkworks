# Plans

Concrete implementation plans for Skunkworks-wide work or larger experiments.

Suggested filename:

```text
YYYY-MM-DD-type-short-slug-plan.md
```

Keep plans current:

- mark when reviewed, enhanced, or completed;
- add dated addenda when discoveries change the approach;
- link related todos and experiment directories.

Tiny throwaway experiments do not need plans unless a plan would actually help.
