# Docs

Cross-experiment documentation for Skunkworks.

## Map

- `HANDOFF.md` — current repository state and session handoff.
- `brainstorms/` — loose idea exploration and shape-finding.
- `plans/` — concrete implementation plans for non-trivial work.
- `solutions/` — durable learnings, debugging notes, and reusable patterns.
- `runbooks/` — repeatable operational recipes.

Experiment-specific notes should usually live inside `experiments/<slug>/` instead. Put docs here only when they affect the repo as a whole or apply across multiple experiments.
